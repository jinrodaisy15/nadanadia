# Taruh foto-foto di sini
# Format yang didukung: JPG, PNG, WebP, GIF
# Nama file bebas — foto akan di-upload melalui website langsung

# Petunjuk upload foto:
# 1. Buka website
# 2. Scroll ke bagian "Galeri Kenangan"  
# 3. Klik "Pilih Foto" atau drag & drop foto ke area upload
# 4. Foto tersimpan otomatis di browser (localStorage)

# Untuk deploy ke GitHub Pages:
# Foto akan tersimpan di browser masing-masing pengunjung
# Jika ingin foto tampil untuk semua orang, taruh di folder ini
# lalu referensikan di Gallery.jsx
